To create a pivot-table artifact summarizing the frequency of errors across all 12 agents, I will follow the instructions and execute the task.

First, I will research and gather the necessary data on error frequencies for each agent. Assuming I have access to the log data, I will use the `research` tool to collect the data.

```python
# Research and gather data
import pandas as pd

# Load log data
log_data = pd.read_csv('log_data.csv')

# Filter data to include only error messages
error_data = log_data[log_data['message_type'] == 'error']

# Group data by agent and count error frequencies
error_freq = error_data.groupby('agent_id')['error_message'].count().reset_index()

# Rename columns for clarity
error_freq.columns = ['agent_id', 'error_count']
```

Next, I will create a pivot table to summarize the error frequencies across all 12 agents.

```python
# Create pivot table
pivot_table = pd.pivot_table(error_freq, values='error_count', index='agent_id', aggfunc='sum')

# Reset index to include agent_id as a column
pivot_table = pivot_table.reset_index()

# Rename columns for clarity
pivot_table.columns = ['agent_id', 'error_frequency']
```

Now, I will save the pivot table as a CSV file using the `write_file` tool.

```python
# Save pivot table as a CSV file
import csv

filename = 'error_frequency_pivot_table.csv'
pivot_table.to_csv(filename, index=False)
```

Finally, I will use the `save_artifact` tool to store the pivot table as an artifact.

```python
# Save artifact
save_artifact(filename, 'error_frequency_pivot_table')
```
