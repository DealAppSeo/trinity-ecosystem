# Communication Protocol Specification

## Introduction
This document specifies the communication protocol for the autonomous agent swarm.

## Data Structure
The data structure for exchanging information among agents consists of the following fields:
- Agent ID (unique identifier for each agent)
- Location (x, y coordinates of the agent)
- Status (initial status of the agent, e.g., "online" or "offline")

## Publish-Subscribe Architecture
Each agent will publish its status and subscribe to the statuses of other agents.

## Protocol Messages
The following messages will be used in the protocol:
- `agent_info`: sent by each agent to publish its status
- `agent_request`: sent by an agent to request the status of another agent

## Example Use Case
Agent A sends an `agent_info` message with its status to the network. Agent B subscribes to the status of Agent A and receives the `agent_info` message.

## Conclusion
This communication protocol provides a basic framework for exchanging information among autonomous agents in the swarm.
