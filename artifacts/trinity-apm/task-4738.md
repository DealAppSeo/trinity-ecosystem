### 🔄 RESTART PROCEDURE

#### Step 1: Sequential Service Restart (Recommended)
```bash
# 1. Restart database services first
railway restart --service postgres
railway restart --service redis

# 2. Restart backend services
railway restart --service api
railway restart --service worker

# 3. Restart frontend services
railway restart --service web
railway restart --service admin

# 4. Restart monitoring/auxiliary services
railway restart --service monitoring
railway restart --service cron
```

#### Step 2: Full Project Restart (Alternative)
```bash
# Restart entire project (all services simultaneously)
railway restart --all

# Or using project ID
railway restart --project <project-id>
```

#### Step 3: Blue-Green Deployment (Zero Downtime)
```bash
# 1. Deploy new version to staging environment
railway deploy --environment staging

# 2. Run validation tests
railway run --environment staging -- npm test

# 3. Switch production traffic
railway link --environment production
railway deploy --detach

# 4. Monitor health before removing old deployment
sleep 60 && railway logs --tail 20
```

### ✅ POST-RESTART VERIFICATION

#### Health Verification Script:
```bash
#!/bin/bash
# verify_restart.sh

SERVICES=("api" "web" "worker" "postgres")
TIMEOUT=120
INTERVAL=10

for service in "${SERVICES[@]}"; do
    echo "Checking $service..."
    for ((i=0; i<TIMEOUT/INTERVAL; i++)); do
        if railway logs --service $service --tail 1 | grep -q "ready\|started\|listening"; then
            echo "✓ $service is healthy"
            break
        fi
        sleep $INTERVAL
    done
done

# Verify connectivity
railway run -- curl -f http://localhost:$PORT/health || echo "Health check failed"
```

### 🐛 TROUBLESHOOTING

#### Common Issues & Solutions:

**1. Services Not Starting:**
```bash
# Check resource limits
railway limits

# View detailed error logs
railway logs --service <service> --error

# Restart with more resources
railway scale --service <service> --memory 1024
railway restart --service <service>
```

**2. Database Connection Issues:**
```bash
# Verify database is ready
railway logs --service postgres | grep "ready for connections"

# Check connection string
railway variables get DATABASE_URL

# Test connection
railway run -- pg_isready -d $(railway vars get DATABASE_URL)
```

**3. Persistent Failures:**
```bash
# Redeploy from scratch
railway deploy --service <service> --detach

# Rollback to previous version
railway deployments
railway deploy --version <stable-version-id>
```
