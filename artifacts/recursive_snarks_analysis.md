### Example Code
Here is an example of a basic recursive function in Python that calculates the factorial of a given number:
```python
def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n-1)
```
This function demonstrates the recursive principle, where the solution to a problem depends on the solution to a smaller instance of the same problem.
