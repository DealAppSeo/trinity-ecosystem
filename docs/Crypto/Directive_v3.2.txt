21.4 TORCH Agent â€” Graceful Degradation for New Assets
TORCH depends on influencer_rep_scores being seeded for each asset. The 4 extended ATS assets (DOT, AAVE, LTC, UNI) and 2 AI tracking assets (TAO, FET) have no initial seed data. TORCH must degrade gracefully rather than hallucinate.
Required logic before emitting any TORCH signal:
Query influencer_rep_scores for the asset. If no rows exist â†’ return NO_SIGNAL with hallucination_risk=HIGH and evidence='INSUFFICIENT_NARRATIVE_DATA'
BFT consensus continues without TORCH's vote â€” 4 of remaining 4 agents must agree instead
Log the degradation event so postmortem can attribute absent TORCH data
After Santiment/LunarCrush keys registered, seed narrative data for all 6 new assets â€” TORCH activates automatically when rows exist
Scope warning: 
If TORCH logic lives in a shared base class (ConstitutionalAgent.ts), scope the degradation check specifically to TORCH and specifically to assets where alpacaTradable=false or influencer_rep_scores count=0. Do not apply broadly to other agents.
