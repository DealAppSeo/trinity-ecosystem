# Capability Gap Report: Path to Full Agentic Autonomy

This report identifies the technical gaps preventing the Trinity Swarm from executing advanced artifacts (Performas, Video, Prototypes) and proposes the necessary infrastructure to bridge them.

## 1. Goal: Business Plans & Financial Performas
**Current State**: Basic stock quotes (AlphaVantage) and simple spreadsheet creation (Google Workspace).
**Gaps**:
- **Data**: Missing company fundamentals (Balance Sheet, Cash Flow) and macro-economic data.
- **Logic**: No iterative Sheet manipulation tools (Append/Read/Update).
- **Tooling**: Missing numerical simulation engines for ROI/Burn-rate projections.
**Required**: 
- [ ] Upgrade `AlphaVantageMCP` with `get_company_fundamentals`.
- [ ] Upgrade `GoogleWorkspaceMCP` with `read_spreadsheet` and `append_values`.
- [ ] Add `MathEngineMCP` or use Python-in-Sandbox for financial math libs.

## 2. Goal: Multimodal Content (Video/Audio)
**Current State**: Image generation only (Stability AI).
**Gaps**:
- **Video**: No tools for video generation (Runway, Luma, HeyGen).
- **Audio**: No tool for voice synthesis (ElevenLabs).
**Required**:
- [ ] Implement `ReplicateMCP` to access 1000+ specialized models (Video, Audio, Llama-DeepReasoning).
- [ ] Env Var: `REPLICATE_API_KEY`.
- [ ] Integrate `ElevenLabsMCP` for high-fidelity voice.

## 3. Goal: Rapid Prototyping & Deployment
**Current State**: Local Sandbox and GitHub PRs.
**Gaps**:
- **Environment**: Local sandbox lacks isolation and persistent state.
- **Frontend**: No way to deploy live previews of UI designs.
**Required**:
- [ ] Transition `ActionSandbox` to **E2B (Excelsior)** for isolated cloud compute.
- [ ] Integrate `VercelMCP` for "Preview Deployment" tool.
- [ ] Env Var: `E2B_API_KEY`, `VERCEL_API_TOKEN`.

## 4. Goal: Advanced Research
**Current State**: General web search (Tavily/You.com).
**Gaps**: No access to academic papers or deep technical documentation.
**Required**:
- [ ] Implement `ResearchMCP` with Semantic Scholar or Arxiv API.

## 5. Goal: Agency (Hire/Ask)
**Current State**: Agents assume they must do it themselves.
**Gap**: No protocol to "Ask a Human" or "Hire a Service".
**Required**:
- [ ] Implement `MarketplaceMCP`: A tool that allows agents to spawn a task in a "Human/External" queue if local confidence is < 40%.
